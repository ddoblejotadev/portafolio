## Buenas prácticas aplicadas

- Código semántico y accesible (HTML5)
- Diseño responsive (mobile-first)
- Estilos separados en CSS propio
- Uso de Git y commits con mensajes claros (Conventional Commits)
- README completo con descripción del proyecto y requisitos
- Despliegue gratuito con GitHub Pages
- Enlaces a repositorios públicos para trazabilidad de cada trabajo

## Características del repositorio

- Sitio estático: `index.html`, `css/style.css`, `js/main.js`
- Despliegue automático mediante GitHub Pages (rama `main`)
- Sin dependencias de terceros ni frameworks de construcción
- Compatible con navegadores modernos

## Razones de las decisiones de diseño

- **HTML/CSS/JS estático**: hosting gratuito y rápido en GitHub Pages, sin costo de servidor.
- **Un solo archivo CSS**: fácil de mantener y sin dependencias externas.
- **Proyectos enlazados a GitHub**: cada trabajo permanece en su propio repositorio original, preservando el historial de commits y evidencias individuales.
- **Diseño limpio y profesional**: prioriza la legibilidad y la presentación para reclutadores y cazatalentos.
